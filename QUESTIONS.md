# Week 8 – Coding Assignment (Category C) — Polymorphism / Inheritance

## Problem 1: The Canteen Billing Counter

**Rules**
- STUDENT → 10% discount
- STAFF → 5% discount
- GUEST → full amount + ₹10 service charge

**Sample**
```
STUDENT 200 → 180.00
STAFF 300   → 285.00
GUEST 150   → 160.00
Total: 625.00
```

## Problem 2: The Campus Parking Charge Calculator

**Rules**
- BIKE → ₹10/hour
- CAR → ₹30 first hour + ₹20 each additional
- TRUCK → ₹50/hour, minimum ₹100

**Sample**
```
BIKE 3  → 30.00
CAR 4   → 90.00
TRUCK 1 → 100.00
CAR 1   → 30.00
Total: 250.00
```

## Problem 3: The Hostel Electricity Bill

**Rules**
- SINGLE → ₹8/unit
- SHARED → ₹6/unit ÷ occupants
- AC → ₹10/unit + ₹200 fixed

**Sample**
```
SINGLE 120     → 960.00
SHARED 150 3   → 300.00
AC 100         → 1200.00
Total: 2460.00
```
